Your event print desk

Mac / Windows · 4 × 6, Letter or 8 × 12 inch sheets

1. Connect this computer to your event

Open your owner dashboard → event → Print desk → Pair a print helper. Paste that code here. This connects the event to this computer; it does not print anything. Pairing leaves printing paused until you start it in the dashboard.

Not paired

Pause this helper first. This checks the dashboard and clears only a run already resolved there, keeping its history. For an unfinished run, inspect the output and resolve it in the event Print desk first. Nothing is reprinted by this button.

Use Start / Pause in your owner dashboard once connected. An uncertain print is held for manual review.

Manual fallback / earlier helper

Paused

Keep this computer awake and connected. Computer-reported completion does not confirm the physical print quality. Resolve uncertain jobs in the print desk before retrying.

2. Select your printer
On Windows, enable “Keep printed documents” in Printer properties → Advanced so this helper can verify the exact job. Retained spool files contain customer photos; remove completed jobs according to your retention policy.
Configure the printer once, then verify the printed size with your ruler and cutter.
3. Print and check a test sheet
This sends one physical sheet to the selected printer. Select your paper size and driver option above, then Save printer settings. The test uses that saved 4 × 6, Letter or 8 × 12 profile; the measuring square remains 3.6 inches.
4. Ready for event printing
After pairing and testing, select Connect validated printer to dashboard above, then Start automatic printing in your dashboard. If a sheet needs confirmation, inspect the physical output and select Printed successfully—continue in the dashboard.
